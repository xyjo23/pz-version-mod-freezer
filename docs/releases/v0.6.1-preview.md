# Project Zomboid Vault 0.6.1 Preview

这是从 PowerShell/WPF 页面向完整桌面版本管理器迁移后的首个 GitHub 预览版本。

## 主要变化

- 自动发现并统一管理 Steam 原版与冻结版本。
- 控制台围绕当前版本提供启动、模组、存档、备份和日志入口。
- 版本管理支持卡片切换和相对版本雷达双击切换。
- 维护工具采用“来源 → 模式 → 名称与目标”的明确冻结制作流程。
- 新版本必须使用用户名称作为主标题，版本号和 BuildID 作为技术信息。
- 兼容旧版带 UTF-8 BOM 的 `freeze.json`，修复已有冻结版不显示的问题。
- 安全完整复制支持 Steam 或冻结版来源；实验性快速模式仅用于冻结版来源。
- 存档、配置、数据库和运行时缓存不会参与硬链接或共享。

## 当前边界

- 共享包正式导入、深度兼容规则和 SHA-256 内容寻址仓库仍在后续阶段。
- 旧冻结版本没有用户名称字段时，会暂时显示原冻结目录标识。
- Windows 包尚未配置商业代码签名证书，系统可能显示“未知发布者”。

完整历史请查看仓库内的 `CHANGELOG.md`。
