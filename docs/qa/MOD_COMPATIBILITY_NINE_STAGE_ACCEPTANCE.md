## 自动化验收门

- `pnpm test:qa`：安全写入、共享包、启动、目录、MOD 中心、规划器、配置档案、迁移、翻译、Lua、PZ 脚本、版本影响、雷达和 TypeScript。
- `pnpm test:analysis:fixtures`：隔离文件系统中的完整性与兼容性判定预言机。
- `pnpm test:profiles:e2e`：真实游戏 JAR 身份下的配置档案创建、比较、应用和撤销。
- `pnpm test:analysis:real`：对真实 Steam/Workshop 数据执行只读分析，报告写入隔离目录。
- `pnpm test:version-impact:real`：42.21.0 冻结版到 42.22.2 Steam 版的真实只读差异报告。
- `pnpm build` 与 `pnpm dist:win`：生产渲染包、Setup 和 Portable 构建。

## 真实数据结论

42.21.0 Build `25485521` → 42.22.2 Build `26486631`：

- 两版各读取 1,004 个原版脚本文件，未出现脚本读取错误。
- 原版脚本定义由 14,153 增至 14,720；当前范围有 5 个 MOD 同键实体命中原版变化。
- 685 个 MOD/原版同路径目标完成核对，其中 192 个原版内容变化；精确旧版原文件副本为 0，因此这些路径不被统一误报为冲突。
- 60 个 MOD 静态引用到的游戏 Class 完成逐类核对：17 个内容变化、0 个移除、0 个未定位。内容变化保留为待验证，不虚报为确定不兼容。
- 更新影响报告为 `complete`，报告摘要与落盘 SHA-256 身份一致。

## 结论边界

- 静态证据不执行 Lua、Java、本地二进制或游戏逻辑。
- 字节变化不是破坏性 API 变化的充分证据；反射、动态类名、Mixin 实际应用仍需启动日志和复制存档验证。
- 真实分析只读 Steam、Workshop 和冻结版；测试报告写入隔离目录，不修改正式版本或存档。
