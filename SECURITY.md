# Security policy

## Supported version

Security fixes currently target the latest preview release.

## Reporting a vulnerability

Please open a GitHub issue without including private save data, account credentials, tokens or complete personal paths. For a vulnerability that should not be public, use GitHub's private vulnerability reporting feature when available.

## Data handling

The application runs locally. It does not upload saves, MOD lists, Steam account data or analytics. Release packages contain only the tool source and documentation; they do not contain Project Zomboid files or Workshop content.
